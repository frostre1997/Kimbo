# Kimbo

A QEMU-based virtual machine emulator for Android.
Fork of the Limbo PC Emulator, modernized for current Android versions.

## Supported Architectures
- x86 / x86_64
- ARM / ARM64
- PowerPC / PowerPC64
- SPARC

## Build
See `README.developers` for native build instructions.
The Android app builds via GitHub Actions — see `.github/workflows/build.yml`.
